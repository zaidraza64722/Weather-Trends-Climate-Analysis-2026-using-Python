# Weather Trends and Climate Analysis – 2026

## Project Overview
This project analyzes historical weather data from five major Indian cities using Python. It explores temperature patterns, rainfall distribution, wind speed, and seasonal variations to identify meaningful weather trends and business insights.

## Cities Covered
- Bengaluru
- Mumbai
- Delhi
- Chennai
- Hyderabad

## Analysis Period
January 1, 2026 – October 30, 2026

## Project Objectives
- Analyze daily and monthly temperature trends.
- Compare rainfall patterns across cities.
- Identify the hottest and coolest cities.
- Examine wind speed and wind gust patterns.
- Explore relationships between weather variables.
- Generate meaningful business insights from weather data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Business Insights
The project investigates:
- Average temperature comparison
- Total rainfall comparison
- Hottest and coolest months
- Average wind speed
- Highest and lowest recorded mean temperatures
- Number of rainy days
- Temperature variation
- Average wind gusts
- Monthly rainfall patterns

## Dataset Source
Historical weather data collected using the Open-Meteo Historical Weather API.

**Data note:** Open-Meteo historical weather data is based on historical weather models and reanalysis datasets. It should not be interpreted as direct measurements from individual weather stations.

## Conclusion
This project demonstrates how Python-based data analytics can be used to explore weather patterns, compare cities, create meaningful visualizations, and communicate data-driven insights.
